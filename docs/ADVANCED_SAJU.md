# 고도화 사주 기능 로드맵

## 현재 구현 완료 기능
- [x] 기본 사주 4기둥 (년/월/일/시) 계산
- [x] 천간/지지/오행/십성 분석
- [x] 양력/음력 변환 (lunar-javascript)
- [x] 이름 입력
- [x] 오행 분포 차트
- [x] 일간 분석, 대운 흐름
- [x] 고급 동양 UI/UX

## 고도화 기능 목록

### Phase 1: 핵심 명리 기능
- [ ] **대운 (大運)** 계산 - 10년 단위 운세 흐름
- [ ] **세운 (歲運)** 계산 - 년도별 세운
- [ ] **월운 (月運)** 계산 - 월별 운세
- [ ] **육친 (六親)** 분석 - 부모, 배우자, 자녀 등
- [ ] **신살 (神殺)** 분석 - 길신/흉신 (천을귀인, 태극귀인 등)
- [ ] **공망 (空亡)** 계산
- [ ] **합충형해 (合沖刑害)** 분석 - 지지간의 관계

### Phase 2: AI 연동
- [ ] Gemini API 연동 - 상세 해석 생성
- [ ] gemma4 로컬 모델 연동 - 오프라인 해석
- [ ] 사용자 질의응답 챗봇 ("이번 달 운세 어때?")

### Phase 3: 데이터/백엔드
- [ ] 사용자 사주 저장 (Supabase/Firebase)
- [ ] 일일/월별 운세 자동 업데이트
- [ ] 궁합 분석 (두 사람 사주 비교)
- [ ] 역사적 인물 사주 데이터베이스

### Phase 4: UI/UX 고도화
- [ ] 3D 오행 시각화
- [ ] 애니메이션 타로카드 스타일 결과 표시
- [ ] 모바일 네이티브 앱 (Capacitor/Expo)
- [ ] 다크/라이트 테마 토글

### Phase 5: 수익화
- [ ] 프리미엄 상세 해석 (유료)
- [ ] 구독형 일일 운세
- [ ] 전문가 상담 연결

## 참고 라이브러리
| 라이브러리 | 용도 | 설치 |
|-----------|------|------|
| lunar-javascript | 음양력 변환 | `npm i lunar-javascript` |
| @google/generative-ai | Gemini API | `npm i @google/generative-ai` |
| framer-motion | 애니메이션 | 이미 설치됨 |
| chart.js | 고급 차트 | `npm i chart.js react-chartjs-2` |
| zustand | 상태관리 | `npm i zustand` |
| supabase | 백엔드/DB | `npm i @supabase/supabase-js` |
